# CodePilot OS

## Mission
Build a production-quality AI Engineering Operating System.

## Tech Stack

Frontend:
- Next.js
- TypeScript
- Tailwind
- shadcn/ui

Backend:
- FastAPI
- Python

Database:
- PostgreSQL

## Rules

- Never break existing code.
- Keep modules small.
- Prefer composition over inheritance.
- Never hardcode secrets.
- Use environment variables.
- Explain architectural decisions.

## Review Checklist

- Builds successfully.
- No lint errors.
- Documentation updated.
- Tests added where appropriate.
